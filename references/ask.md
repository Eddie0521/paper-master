# 问答

目的地是**精准回答**：用户就某篇论文（全文或局部）提问，答案必须硬 grounding 在原文，能指到段落/表号/图号；原文没写的明说「原文未提供」。

## 1. 定位论文

- 参数是 URL/路径 → 按 SKILL.md 抓取规则 fetch，存 `<slug>/paper.md`（已有则跳过抓取）。
- 参数是自然语言 + 可推断的论文（标题、作者、「那篇 X 论文」）→ 先扫数据目录 `card.md` / `plan.md` 标题匹配；匹配不到再问用户要 URL 或路径。
- 参数只含问题、论文已在库里 → 从问题语境或追问确定 `<slug>`。

## 2. 补卡

若 `<slug>/card.md` 不存在，从 `paper.md` 提取生成（模板见 FORMATS.md），深度标「浅读」。已有浅读卡片则直接用，不重复生成。

## 3. 回答问题

- 先读 `card.md` 定位相关字段，不够再回 `paper.md` 深挖。
- 每条结论标注来源：段落号、章节名、表/图编号（原文无编号则用就近标题引用）。
- 原文未涉及的内容直接说「原文未提供」，不凭模型知识补全事实性声明。
- 数值、数据集、基准结果等硬事实必须引原文；推断须标明「推断，非原文」。

## 4. 连接履历（唯一教学基因）

答完后，若 `learning-log.md` 或库里其他 `card.md` 有相关内容，简短一句连接：「这和你读过的 X 的做法不同在…」。无相关则省略，不强行教学。

## 5. 收尾

- 浅读卡片已在步骤 2 落盘，本步不重复写。
- 用户追问同一篇 → 继续 grounding 问答，不自动转精读；用户说「精读这篇」→ 路由到 `references/deep-read.md`。
