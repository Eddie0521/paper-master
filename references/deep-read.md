# 精读

目的地是**精读掌握**：会话结束时，用户能用自己的话复述这篇论文的动机、方法与证据链，能回答"为什么这么设计"级别的问题。每一步都服务这个闭环——讲完不等于读完，复述通过才算。

## 1. 吸收

抓取论文全文转 markdown 存 `<slug>/paper.md`（抓取工具与优先级见 SKILL.md），通读。本地 markdown 直接拷入。完成标准：不看原文能说出论文的主张、方法结构、主要实验及其结论。

## 2. 关键引文

从引用里挑 2-4 篇**关键引文**：直接前驱（本文改进/反驳的对象）、主要 baseline、所用 benchmark 的原文。抓各自摘要或相关章节存 `citations/`；抓取失败标"未验证"。其余引文靠模型知识——讲到拿不准的具体声明（数字、结论、时间线）时明示不确定。

## 3. 摸底

按固定三层骨架列候选节点：

- **前置概念** — 读懂本文必需、但论文默认读者已会的知识
- **领域格局** — 本文接的是哪段话：前序方法、综述视角、benchmark 与评价协议
- **本文** — 论文自身贡献，拆成若干讲解节点

读 `learning-log.md`，履历里学过的前置概念预标为"会"。对剩余前置概念用 AskUserQuestion（multiSelect）问："这些概念哪些你能给别人讲清楚？"

摸底的职责是**防冗余**——别把用户会的讲一遍。防漏不归它管（下潜兜底），所以问勾选、不出考题。

## 4. 阅读计划

写 `<slug>/plan.md`：三层各节点，每节点标 详/略/跳过 加一句理由（"自评会→跳过"、"履历学过→略"、"本文核心→详"）。空层省略。

把计划摆给用户批改（"跳过X""重点讲Y"），确认后开讲。此后计划就是导航图：每讲完一个节点更新进度标记——这也是断点续读的锚。精读一篇论文跨多次会话是常态，随时可停。

## 5. 速览

开讲第一件事，永不跳过：几分钟讲清这篇论文**主张什么、为什么重要、接的是哪段话**。后面每个节点的动机都挂在这里。

## 6. 按层推进

沿计划从外层往里讲。每个节点：

- **三配料**：具体例子走一遍（抽象概念/方法配数值或玩具例子）；图示（结构性内容用图——可视化工具可用时用富图，否则 mermaid/ASCII）；连接旧知识（"这是你履历里 X 的变体，差别在…"）。
- 讲完过**闸门**：AskUserQuestion 问 继续/跳过/再深入。闸门只控节奏，不考试。
- 讲解中发现用户缺一个摸底没测到的前置概念 → **下潜**：暂停主线当场补讲，补完即回，该概念记入本次学到清单。
- 更新 `plan.md` 进度标记。

每层结束过**检验**：1-2 道开放综合题，必须用户自己组织答案（选择题会退化成认读）。答错的点换角度重讲、再验，通过才进下一层。检验结果记入 `plan.md`。

## 7. 终考

请用户用自己的话完整复述：**动机 → 方法 → 证据链**。对照 `paper.md` 指出复述中的漏洞与含糊处；大漏洞回讲补上。完成标准：复述覆盖三段、无硬伤。

## 8. 归档

- 写 `<slug>/archive.md`（**阅读档案**）：用户复述原文（少编辑）+ 指出的漏洞 + 会话关键问答 + 最终计划快照。
- 写 `<slug>/card.md`（**论文卡片**，模板见 FORMATS.md）：从 `paper.md` 提取，不依赖用户复述；深度标"精读"。已有浅读卡片则升级为精读并补全。
- `learning-log.md` 追加本次学到的概念（含下潜补讲的），一行一条。
- `plan.md` 状态改"已终考"。
