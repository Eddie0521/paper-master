# 跨篇

目的地是**跨语料综合**：在作用域内（多篇论文、共性/对比/回忆/教学——由当次请求决定）产出有据结论，每条标来源论文与深浅。

## 1. 确定作用域

从用户请求提取：
- **主题/问题** — 要回答什么（共性、差异、演进、某维度横评等）
- **语料范围** — 显式列出的论文、关键词匹配的库内论文、或「全部读过」

若范围模糊，用 AskUserQuestion 确认：哪些论文纳入、是否限定「只看精读过的」。

## 2. 语料选择与深浅声明

扫描数据目录，按范围筛选 `<slug>/`：
- 读各 `card.md`；无卡则按懒回填规则从 `paper.md` 补卡。
- 列出纳入语料并声明深浅：精读 N 篇、浅读 M 篇。
- 用户要求「只看精读过的」→ 过滤深度标记非「精读」的条目。
- 跨篇分析默认全纳入但必须在开场声明深浅；用户可事后收窄。

## 3. 综合

- **先卡片、后原文**：优先从各 `card.md` 取问题/方法/数据/结论/局限；卡片不够或需细节验证时回 `paper.md`。
- 每条结论标注来源：`<slug>` + 字段或段落引用。
- 允许跨篇推断，但须标明「综合推断」并列出依据论文。
- 需要时写 `syntheses/<主题-kebab>.md`（模板见 FORMATS.md）；用户未要求持久化则口头交付。

## 4. 模式变体（同一流程，不同侧重）

| 用户意图 | 侧重 |
|---|---|
| 找共性 | 方法/问题/数据协议横比，归纳重复模式 |
| 找差异 | 对比表，标关键分歧点与可能原因 |
| 回忆辅助 | 轻量回顾，帮用户唤起读过内容的结构 |
| 教学串联 | 按时间线或概念链组织，连接 learning-log |

不预设任务类型——解析用户句子的动词与目标即可。

## 5. 连接履历

`learning-log.md` 中相关概念可辅助组织叙事（「你之前在 X 学过 Y，这几篇分别…」），但不替代论文级引用。
